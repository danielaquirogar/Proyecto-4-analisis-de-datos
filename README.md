# Análisis de Impacto Estadístico e Inferencia para Políticas Públicas (Python).

Realicé un estudio de estadística inferencial basado en metodologías del Ministerio de Educación comparando el rendimiento académico
entre grupos de control y tratamiento en establecimientos de educación escolar.

Apliqué pruebas de hipótesis estadísticas para determinar la significancia de una nueva metodología educativa
utilizando datos estructurados de la plataforma SENCE.

Resultado: sin evidencia estadísticamente significativa de mejora con la nueva metodología educativa (p = 0,167), concluyendo con rigor y sin forzar resultados.
